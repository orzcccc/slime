## 文档维护约定

- 主策划案只保留概要、跨系统关系和系统文档链接。
- 详细数值、概率、经济公式、数据结构、API 契约和验收标准放入 `Systems/` 下的独立文档。
- 已实现规则标注“已实现”；尚未确认的设计必须标注“提案”“待确认”或“待办”。
- 实现行为变化时，代码与对应系统文档必须在同一次任务中同步更新。
- 项目按正规 PC 商业项目标准开发，任务完成定义、性能基线、合规要求和上线阻塞项见 `.cursor/rules/commercial-pc-standards.mdc`。原型阶段的占位方案必须在文档中标注，并在上线前清除。
