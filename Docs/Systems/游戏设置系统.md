## 一、页面与交互

设置面板与背包面板同尺寸（655×688，复用背包面板外框），在岛屿窗口范围内展开，打开期间隐藏岛屿、顶栏和底栏；面板外的透明区域照常点击穿透到桌面。顶部三个页签（G09）切换页面，× 或 Esc 关闭。所有修改即时生效并自动保存，没有保存按钮。

| 页面 | 内容 | 规则 |
| --- | --- | --- |
| S01 窗口 | 始终置顶、开机自启、锁定位置三个开关（G12）；窗口缩放 100/125/150/200% 四档（G14）；重置窗口位置（次按钮 G04）；“修改即时生效并自动保存”提示 | 见第二节 |
| S02 声音与提醒 | 音效开关 + 音量滑条（G13）；背景音乐开关 + 音量滑条；盲盒存满提醒开关；开箱动画“完整 / 快速”两档 | 开关关闭时对应滑条显示禁用态；拖动滑条实时调音量，松开音效滑条试听一次 |
| S03 账号与关于 | 头像、昵称、登录状态与累计开箱次数；版本号（只读）；用户协议、隐私政策入口；退出游戏按钮 | 见第三节 |
| S04 退出确认层 | 标题、离线产出说明（“最多存 N 个”取当前凝聚台容量）、取消 / 退出 | 退出关闭进程；取消或 Esc 回 S03 |

失败处理：系统调用（置顶、自启注册表、缩放）或本机设置写入失败时，开关回到原状态并在面板底部显示 2 秒轻提示（G05）。

## 二、窗口设置（S01）

- **始终置顶**：`SetWindowPos(HWND_TOPMOST / HWND_NOTOPMOST)`，启动时按保存值恢复。默认关闭。
- **开机自启**：写入当前用户注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\SlimeBlindBox`（值为带引号的程序路径），不需要管理员权限；状态以注册表为准，游戏目录移动后会自动更新登记的路径。Editor 中开关为禁用态，避免把 Unity 编辑器登记为开机启动。
- **锁定位置**：开启后按住岛屿不再拖动窗口，按钮、滑条等控件照常可用。
- **窗口缩放**：窗口实际像素 = 800 × 档位，界面按同一比例缩放（根 Canvas `scaleFactor`），布局比例不变；缩放时保持窗口中心不动，超出屏幕时整体挪回所在显示器工作区内。首次启动没有选择过时，按系统 DPI（`GetDpiForSystem` / 96）取最接近的一档。Editor 中只记录档位，不改变 Game 视图。
- **重置窗口位置**：窗口移到主屏幕工作区右下角并保存位置。

## 三、账号与关于（S03）

- 头像与昵称来自登录信息，游戏内不可修改。当前为本地档案登录，状态显示“本地档案登录 · 累计开箱 N 次”，头像使用默认史莱姆头像；接入 Steam 后改为 Steam 头像、昵称和“已通过 Steam 登录”。昵称读取失败时显示“Steam 玩家”。
- 累计开箱次数由后端 `GameStateDto.total_boxes_opened` 下发（存档 v2 新增，见 [游戏后端与本地存档](游戏后端与本地存档.md)），与将来的 Steam 好友状态文案同源。
- 版本号读取 `Application.version`。
- 用户协议、隐私政策用系统浏览器打开 `ExternalLinks` 中的地址。**正式地址尚未确定**，当前为空，点击时提示“链接暂未开放”（已列入上线阻塞项）。

## 四、退出流程（S04）

- 账号页“退出游戏”、托盘菜单“退出”、Alt+F4 等系统关闭请求（`Application.wantsToQuit`）都弹出同一确认层。托盘触发且岛屿隐藏时，先显示岛屿再打开设置的账号页与确认层。
- 正在播放开箱动画（M05）时“退出”按钮禁用，并提示“开箱完成后再退出”。
- 确认后：Editor 停止 Play Mode，Player 调用 `Application.Quit()`。

## 五、声音与开箱动画（S02）

- `GameAudio` 挂在应用根节点，音效、背景音乐各一路 `AudioSource`，音量与开关来自 `LocalSettings`。
- 正式音频尚未制作：背景音乐从 `Resources/Audio/Bgm` 加载，缺失时不播放；试听音效从 `Resources/Audio/SfxPreview` 加载，缺失时使用程序生成的 0.12 秒提示音（**占位**，已列入替换清单）。
- 开箱动画“快速”把 M05 晃动动画从 18 帧缩短到 8 帧。“高稀有特效仍完整播放”针对 M07 揭示特效，该特效尚未实现，实现时不受此选项影响（待办）。

## 六、盲盒存满提醒与系统托盘（S06）

- 托盘图标 16/24/32/48/256 多尺寸 `.ico`，常态与存满（右下角红点）两套，位于 `Assets/StreamingAssets/Tray/`，按系统小图标尺寸加载。
- 左键：显示 / 隐藏岛屿。右键：Windows 原生菜单——显示/隐藏岛屿（文字随状态切换）、始终置顶（勾选）、锁定位置（勾选）、重置窗口位置、设置...、退出。勾选项与 S01 开关走同一处理逻辑，保持同步。“设置...”显示岛屿并打开 S01，“退出”走 S04。
- 待领取达到凝聚台容量时切换存满图标；开关开启时，从未满变为存满发送一条系统通知（每次存满只发一条，启动时已存满不发）。系统通知总开关关闭（`HKCU\...\PushNotifications\ToastEnabled = 0`）时不发送，S02 开关下方显示“系统通知已关闭，请在 Windows 设置中开启”，开关仍可操作。
- 资源管理器重启后自动重新登记托盘图标。原生托盘只在 Windows Player 中启用。

## 七、本机设置存储

`LocalSettings` 使用 PlayerPrefs 保存本机偏好（不涉及玩家资产，不走后端），读取时校验取值，缺失或损坏回退默认值：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `settings.window.topmost` | 关 | 始终置顶 |
| `settings.window.lock` | 关 | 锁定位置 |
| `settings.window.scale` | 未设置 | 100/125/150/200，未设置时跟随系统缩放 |
| `settings.audio.sfx.enabled` / `volume` | 开 / 0.8 | 音效 |
| `settings.audio.bgm.enabled` / `volume` | 开 / 0.6 | 背景音乐 |
| `settings.notify.boxfull` | 开 | 盲盒存满提醒 |
| `settings.anim.fastopen` | 关 | 开箱动画“快速” |

开机自启不存 PlayerPrefs，以注册表为准。

## 九、验收标准

- 三个页签切换正确，× 与 Esc 关闭设置；退出确认层打开时 Esc 只关闭确认层。
- 置顶、锁定、缩放、存满提醒、开箱动画、音量设置重启后保持；开机自启在注册表中增删，重启电脑后自动出现在桌面。
- 缩放到 200% 时窗口与界面等比放大且完整位于屏幕内；首次启动按系统缩放选择最接近的一档。
- 锁定后按住岛屿不能拖动，点击按钮正常。重置后窗口位于主屏幕右下角。
- 关闭音效后滑条为禁用态且不可拖动；松开音效滑条时试听一次。
- 待领取从未满变为存满时托盘图标出现红点并发送一条通知；关闭提醒后不再发送。
- 托盘菜单勾选项与设置开关一致；托盘“退出”、账号页“退出游戏”、Alt+F4 都弹出确认层；开箱动画播放中“退出”禁用。
- 系统调用或保存失败时开关回到原状态并显示轻提示。
- 所有文字在 800×800 下不换行、不溢出。
