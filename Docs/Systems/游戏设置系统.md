# 游戏设置系统

> 状态：已实现（显示设置与退出游戏）  
> 最后更新：2026-11-04  
> 主策划入口：[《史莱姆盲盒》项目策划案](../史莱姆盲盒-项目策划案.md)  
> 关联代码：`Assets/Scripts/UI/GameSettingsService.cs`、`Assets/Scripts/UI/GameSettingsView.cs`、`Assets/Resources/UI/GameSettings.prefab`

> 待调整：游戏将改为固定约 `800×800` 的透明无边框桌面岛屿窗口（见 [桌面岛屿窗口系统](桌面岛屿窗口系统.md)）。实现后，本文中的显示模式、分辨率选项和 `1920×1080` 默认值将移除，设置弹窗保留退出游戏等功能。

## 一、功能范围

当前游戏设置提供：

- 显示模式选择：全屏、无边框、窗口化。
- 常用分辨率选择与应用。
- 退出游戏。
- 显示设置本地持久化，并在下次启动时自动应用。

音频、语言、画质等级、帧率上限和按键设置不在本阶段范围内。

## 二、默认规则

- 玩家首次启动时默认分辨率为 `1920×1080`。
- 玩家首次启动时默认显示模式为“无边框”。
- 首次写入默认值后，后续启动以玩家上次成功应用的设置为准，不再覆盖。
- Unity Editor 中执行“退出游戏”时停止 Play Mode；正式构建中调用 `Application.Quit()`。

## 三、显示模式映射

- **全屏**：`FullScreenMode.ExclusiveFullScreen`，由系统独占显示设备。
- **无边框**：`FullScreenMode.FullScreenWindow`，使用无边框全屏窗口。
- **窗口化**：`FullScreenMode.Windowed`，以普通可移动窗口运行。

## 四、可选分辨率

当前提供以下常用比例为 16:9 或接近 16:9 的分辨率：

- `1280×720`
- `1366×768`
- `1600×900`
- `1920×1080`
- `2560×1440`
- `3840×2160`

列表为游戏明确支持的常用档位，不直接暴露系统返回的重复刷新率组合。低于显示器原生能力的选项是否真正生效由操作系统、显卡驱动和 Unity 显示模式共同决定。

## 五、Prefab 与交互结构

- 设置入口位于 `MainUI.prefab` 顶栏右侧。
- 设置弹窗是独立真实资源 `Assets/Resources/UI/GameSettings.prefab`，运行时通过 `Resources.Load<GameObject>("UI/GameSettings")` 加载。
- 弹窗静态结构包含标题、显示模式下拉框、分辨率下拉框、状态提示、应用、关闭和退出游戏按钮。
- `GameSettingsView` 只负责控件绑定与交互；`GameSettingsService` 负责默认值、持久化和 `Screen.SetResolution` 调用。
- 弹窗打开时置于主界面最上层；关闭只隐藏实例，不重复加载资源。

## 六、持久化约定

设置使用 `PlayerPrefs` 本地保存：

- `settings.display.initialized`
- `settings.display.width`
- `settings.display.height`
- `settings.display.mode`

每次点击“应用”后立即保存。启动阶段在场景加载前读取并应用，避免进入主界面后再次切换窗口造成明显闪烁。

## 七、验收标准

- 清空本地设置后首次启动采用 `1920×1080` 和无边框模式。
- 三种显示模式均可选择并调用对应 Unity 显示模式。
- 六档常用分辨率均可选择，应用后状态提示显示所选值。
- 退出并重新启动后恢复上次应用的分辨率和显示模式。
- 设置弹窗为独立 Prefab，主界面运行时代码不拼装其静态层级。
- Editor 中退出按钮停止运行，Player 构建中退出按钮关闭进程。
