# 背包与物品界面

> 状态：已实现  
> 最后更新：2026-11-04  
> 主策划入口：[《史莱姆盲盒》项目策划案](../史莱姆盲盒-项目策划案.md)  
> 关联资源：`Assets/Resources/UI/MainUI.prefab`、`Assets/Resources/UI/InventoryItem.prefab`、`Assets/Sweet Land GUI/`、`Assets/Resources/icon/`

## 一、页面定位

背包是玩家查看持有史莱姆的入口，显示史莱姆图片、名称、品质、数量、等级与有效 CP。

盲盒不属于背包，使用底部导航中的独立“盲盒”页面。

## 二、物品图标规则

- 每个背包条目必须有独立图标区域，不允许只显示纯文本行。
- 当前史莱姆尚无完整图鉴图标时，复用 Pixel Adventure 2 的史莱姆序列帧作为临时图片，并根据 `slime_id` 选择不同帧、叠加轻度品质色。
- 正式史莱姆图标应按 `slime_id` 绑定资源，并保持同一尺寸、边距和锚点。

## 三、Prefab 结构

- `MainUI.prefab`：背包页面和滚动容器。
- `InventoryItem.prefab`：自包含的史莱姆列表项模板，内部固定包含图片、名称和详情；运行时不得再向条目追加静态控件。
- 所有模板由 Unity Editor API 生成并保存为真实 Prefab；运行时仅加载模板、绑定数据和事件。

## 四、交互规则

- 从底部“背包”进入页面，显示史莱姆列表。
- 史莱姆列表操作仍由服务端校验资源；客户端按钮状态只用于交互提示。

## 五、响应式布局约束

- Canvas 基准分辨率为 `1280×720`，采用 `Scale With Screen Size`，高度匹配权重为 `0.65`，优先保证窄窗口中的纵向可用空间。
- 所有静态页面位于 Safe Area 容器内，窗口尺寸或安全区域变化时重新计算锚点。
- 宽屏（宽高比不低于 1.45）主页采用培养皿左侧、状态/GM 右侧双栏；窄屏或宽度低于 900 时自动改为上下布局。
- 底部导航根据窗口宽度缩小间距和边距，按钮文字启用 Best Fit，禁止横向溢出。
- 动态物品行最小高度为 96，文字允许换行并截断纵向溢出；列表始终置于 `ScrollRect + RectMask2D` 内。
- 页面和列表项必须使用锚点、布局组与最小尺寸约束，不允许依赖单一分辨率下的绝对坐标。
- Canvas 的宽高匹配权重随当前宽高比调整：宽屏偏均衡、标准屏偏高度、窄屏进一步保障纵向空间。
- 主页在窄屏下切换为上下结构；宽屏保持培养皿与操作区左右双栏。

## 六、网格与分页规则

- 史莱姆内容使用 `GridLayoutGroup + AdaptiveGridLayout + ContentSizeFitter`。基准宽屏最多 4 列，容器变窄时自动降为 3、2、1 列，单格最小宽度 `230`、高度 `150`、间距 `12`。
- 史莱姆背包每页最多显示 8 个条目；上一页/下一页按钮和页码位于背包底部。
- 页码必须限制在有效范围，首页禁用上一页，末页禁用下一页；库存刷新导致总页数减少时自动回退到最后有效页。
- 物品条目由 `InventoryItem.prefab` 实例化，必须保留图标、名称/品质、数量、成长信息和操作区，不再使用纯文本纵向行。
- Grid 内容节点顶部对齐并横向拉伸，`ContentSizeFitter` 根据实际行数计算高度；刷新或翻页后强制重建布局并将滚动位置复位到顶部。

## 七、Sweet Land GUI 视觉资源

- 主界面背景、顶栏、底部导航、培养皿卡片、背包滚动区域、分页栏、设置弹窗和物品卡使用 `Sweet Land GUI` 的可切片 Frame Sprite。
- 常规按钮使用该资源包的 Trapezoid Button Sprite；设置入口额外使用 `Icon_Settings`。
- 九宫格边框必须保留资源原有 Sprite Border，并将 uGUI `Image.type` 设为 `Sliced`，禁止直接拉伸导致圆角或边框变形。
- Sweet Land GUI 原始资源继续保留在其资产目录中；由项目 Prefab 直接序列化引用，不复制到 `Resources`，运行时也不按路径加载该素材。
- 文本、品质色和史莱姆图片仍由项目自己的引用组件及运行时代码绑定，视觉素材不承载玩法数据。

- `图标1.png`：背包底部导航图标。
- `图标2.png`：图鉴底部导航图标。
- `图标3.png`：公会底部导航图标。
- `图标4.png`：暂未使用（原排行榜导航图标，排行榜已移除）。

- `页签底.png`：底部导航按钮底图。
- `图标底.png`：保留为后续独立图标槽底图。
- `弹窗UI.png`：游戏设置弹窗主面板。
- `弹窗UI绿.png`：开发者工具等辅助功能卡片。

导航按钮采用“上方图标、下方文字”结构，图标保持等比缩放且关闭 Raycast；新增图标不得遮挡按钮文字或独立拦截点击。盲盒图片只表达品质外观，库存数量、品质名称与可开启状态仍以服务端数据为准。
