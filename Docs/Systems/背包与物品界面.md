## 一、页面定位

背包是玩家查看持有史莱姆的入口。点击底部功能坞的“背包”打开 `InventoryPopup`，面板占据 `800×800` 窗口中央，打开期间隐藏岛屿、顶栏、底栏和消息条；面板外的透明区域照常点击穿透到桌面。盲盒不属于背包，使用功能坞中的独立“盲盒”页面。

## 二、B01 背包列表

- 顶部标题“背包”，右上角关闭按钮。
- 汇总行：`持有 N 种 · 共 M 只 · 总CP X`。总 CP 取后端游戏状态的 `total_cp`，状态尚未读取时用背包条目的 `effective_cp` 之和。
- 排序按钮和筛选按钮，按钮上写当前条件，例如“排序：品质 高→低”“筛选：全部品质 / 筛选：传说 / 筛选：已选 3 种品质”。
- 卡片区固定 4×2 共 8 格，不滚动。每页由 `InventoryItem.prefab` 实例化的 8 张卡复用，多余的隐藏。
- 卡片内容：品质卡框与品质名、岛上展示标记（左上）、同种持有数量角标（右上）、立绘、名称、`Lv.等级 · CP 单只有效CP`。
- 神器（阶级 7）及以上的卡片在卡框外有品质色的呼吸光边（`RarityFrameGlow`，周期 1.6 秒）。
- 翻页器：上一页 / 页码 / 下一页；也可在面板上滚动鼠标滚轮翻页。只有 1 页时两个箭头都置灰。
- 操作：点卡片进入 B03；点“排序”打开排序下拉；点“筛选”打开 B02；关闭按钮或 Esc 回主界面。

### 排序

默认“品质 高→低”。排序只改变显示顺序，不修改玩家数据。

| 选项 | 主排序 | 次排序 |
| --- | --- | --- |
| 品质 高→低 | 品质阶级降序 | 单只有效 CP 降序 |
| CP 高→低 | 单只有效 CP 降序 | 品质阶级降序 |
| 等级 高→低 | 等级降序 | 单只有效 CP 降序 |
| 最近获得 | 首次获得时间降序 | - |
| 数量 多→少 | 持有数量降序 | 品质阶级降序 |

以上均以 `slime_id` 升序作为最终次序，保证结果稳定。排序下拉与 B02 共用同一弹层底板，锚定在排序按钮下方，5 个选项单选，选中立即生效、回到第 1 页并关闭。

### 空状态与失败

| 情况 | 卡片区显示 | 按钮 |
| --- | --- | --- |
| 背包读取中（尚未成功读取过） | 正在读取背包…… | 无 |
| 读取失败 | 背包读取失败，请稍后重试 | 重试：未登录时重新登录，否则重新读取背包与图鉴 |
| 背包为空 | 还没有史莱姆，去开个盲盒吧 | 去开盲盒：关闭背包并打开盲盒页 |
| 筛选无结果 | 没有符合条件的史莱姆 | 重置筛选：清空品质筛选 |

读取失败不显示为空背包。是否读取成功由 `SlimeGameController.InventoryLoaded` 判断。

## 三、B02 品质筛选层

- 弹层位于背包面板内，透明遮罩覆盖整个面板；点击遮罩关闭且不应用。
- 标题“按品质筛选（可多选）”，十二档品质选项 3 列 × 4 行，按阶级从劣质到魔神排列。选项只用色块表示品质，不放史莱姆形象。
- 选项两态：未选中为浅色底；选中为浅青底加深色描边和 √。
- “重置”清空当前选择；“确定”应用并回到 B01 第 1 页。没有选中任何品质时等同“全部品质”。
- 品质名与色块来自数值配置 `GameBalanceConfig.SlimeRarities`；接入 PlayFab 后改为云端下发的品质表。

## 四、B03 史莱姆详情

详情与列表共用背包面板和关闭按钮，进入详情时隐藏列表。

- 左上“< 返回”回到 B01 原页码，排序与筛选保持不变；Esc 同样返回列表。
- 品质飘带：白色可染色切图，按 `rarity_color` 着色，文字按底色深浅自动用白字或深色字。
- 左右箭头或键盘 ←/→ 切换当前排序筛选结果中的上一种 / 下一种，到两端时对应箭头置灰。
- 立绘放在底座上；下方名称、`持有 ×N · 首次获得 yyyy-MM-dd`。
- 信息框：等级与经验条、基础 CP 与有效 CP（含等级加成倍率）、本种合计 CP。只持有 1 只时隐藏“本种合计”。
- 经验来源尚未确定，经验条固定为锁定态并显示“升级方式待开放”。
- “在图鉴中查看”关闭背包并打开图鉴页。
- “放到岛上展示”当前禁用，见第六节待办。

有效 CP = floor(基础 CP × (1 + log2(等级) × 0.25))。数值由后端下发，客户端只展示：

| 字段 | 含义 |
| --- | --- |
| `base_cp` | 基础 CP |
| `unit_effective_cp` | 单只有效 CP |
| `effective_cp` | 本种合计有效 CP = 单只有效 CP × 数量 |
| `level_cp_multiplier` | 等级加成倍率，Lv.2 为 1.25 |
| `first_obtained_at` | 首次获得时间，UTC ISO 8601 |

## 五、Prefab 与代码结构

```text
InventoryPopup              铺满窗口 + InventoryPopupView（排序、筛选、翻页、详情切换、键盘与滚轮）
└─ panel                    背包面板底图（中心锚点 655×688）
   ├─ listPage              B01：标题牌、汇总、排序/筛选按钮、cardGrid、statePanel、翻页器
   ├─ detailPage            B03 + SlimeDetailView（只负责展示）
   ├─ closeButton           列表与详情共用
   ├─ sortLayer             透明遮罩 + 排序下拉
   └─ filterLayer           透明遮罩 + B02 筛选层
```

- `InventoryItem.prefab`：背包卡片。根节点 Image 是动态描边光边（比卡框大一圈），`cardButton` 是卡框与点击区域。
- `QualityOptionItem.prefab`：筛选选项与排序选项共用的条目，两态切换底图并显示 √。
- 卡片和选项都由 `InventoryPopupView` 在初始化时一次性实例化，之后只刷新数据。
- 卡框和立绘由 `SlimeArtCatalog` 按品质键和 `slime_id` 从 `Resources/Sprites/Bag/` 加载并缓存，缺图时回退到普通品质资源并输出警告。
- 文案集中在 `InventoryUiText`；排序与筛选逻辑在 `InventoryListQuery`。
- 旧版 `MainUI.prefab` 内的 `InventoryPage`（滚动列表 + PixelAdventure 史莱姆帧）已删除。

## 七、验收标准

- 打开背包时岛屿、顶栏、底栏隐藏，关闭后恢复；面板外点击穿透到桌面。
- 默认按品质高到低排列，同品质按单只有效 CP 降序；5 种排序选项切换后回到第 1 页。
- 筛选多选生效，确定后回第 1 页；点遮罩关闭不应用；全不选等同全部品质。
- 翻页按钮、滚轮翻页在首页和末页正确置灰或不响应。
- 读取中、读取失败、空背包、筛选无结果四种状态显示对应文案和按钮。
- 神器及以上卡片有呼吸光边，其他品质没有。
- 详情左右切换遵循当前排序和筛选，返回后停留在原页码；数据刷新后详情条目消失时自动回到列表。
- 所有单行文字在 `800×800` 下不换行、不溢出。
