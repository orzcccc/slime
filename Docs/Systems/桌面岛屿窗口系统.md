# 桌面岛屿窗口系统

> 状态：提案（已确认方向，待实现）  
> 最后更新：2026-11-05  
> 主策划入口：[《史莱姆盲盒》项目策划案](../史莱姆盲盒-项目策划案.md)  
> 关联文档：[游戏设置系统](游戏设置系统.md)、[背包与物品界面](背包与物品界面.md)

## 一、设计目标

《史莱姆盲盒》是一款常驻桌面的陪伴型游戏。游戏不占满屏幕，只有一座漂浮的小岛停在桌面上，玩家照常工作，随时看一眼岛上的史莱姆，或者顺手开个盲盒。

## 二、主界面形态

- 主界面是一片岛屿，培养皿、史莱姆和盲盒产出都在岛上表现。
- 岛屿以外的区域完全透明，玩家能直接看到后面的桌面和其他窗口。
- 背包、盲盒、图鉴、公会等功能页面在岛屿窗口范围内以面板或弹窗展开，不另开新窗口。

## 三、窗口规格

| 项目 | 规则 |
| --- | --- |
| 窗口尺寸 | 固定约 `800×800`，玩家不可拉伸缩放 |
| 边框 | 无边框，无标题栏和系统按钮 |
| 背景 | 透明，只渲染岛屿和 UI 本身 |
| 显示模式 | 只有桌面窗口一种，不提供全屏或分辨率切换 |
| 任务栏 | 保留任务栏图标，方便找回和关闭 |

`800×800` 指逻辑尺寸。高 DPI 显示器上是否按系统缩放比例放大，待确认。

## 四、拖动与位置

- 玩家按住岛屿的任意非按钮区域，可以把整个游戏窗口拖到桌面上任意位置。
- 拖动结束后保存窗口位置，下次启动时恢复到原位置。
- 窗口至少保留一部分在屏幕可见范围内，防止拖出屏幕后找不回来。分辨率或显示器变化导致保存的位置无效时，窗口回到主屏幕中央。
- 支持在多显示器之间拖动。

## 五、透明区域交互

- 透明区域的鼠标点击穿透到下面的桌面或其他窗口，岛屿外的空白处不会挡住玩家操作。
- 岛屿和 UI 等不透明区域正常响应点击和拖动。

## 六、待确认

- 窗口是否默认置顶，以及是否在设置里提供“始终置顶”开关。
- 原案中的“极简长条窗口”和“吸附屏幕边缘”是否作为后续的附加模式保留。
- 高 DPI 下的窗口缩放规则。
- 退出入口的位置（设置弹窗、任务栏右键或托盘图标）。

## 七、技术要点（Windows）

- Unity 相机使用 Alpha 为 0 的纯色背景，URP 需要保证最终输出保留透明通道。
- 通过 Win32 API 去掉窗口边框，并使用 DWM 让窗口背景透明。
- 拖动通过 Win32 移动窗口实现，避免依赖系统标题栏。
- 点击穿透根据鼠标所在位置是否命中岛屿或 UI 动态切换。
- 以上能力只在 Windows Player 构建中生效；Unity Editor 内按普通 Game 视图显示，便于开发调试。

## 八、验收标准

- 首次启动时窗口约为 `800×800`，无边框，岛屿以外区域能看到桌面。
- 按住岛屿可拖动窗口，松开后位置保持；重启游戏后恢复到上次位置。
- 点击岛屿外的透明区域时，操作落到下面的桌面或窗口。
- 窗口不能被拖到完全不可见；显示器配置变化后窗口仍能出现在屏幕内。
- 各功能页面都在 `800×800` 范围内完整显示，没有内容被裁切。
