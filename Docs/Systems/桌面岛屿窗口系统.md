# 桌面岛屿窗口系统

> 状态：已实现（窗口能力）；正式岛屿主界面美术布局持续迭代  
> 最后更新：2026-11-05  
> 主策划入口：[《史莱姆盲盒》项目策划案](../史莱姆盲盒-项目策划案.md)  
> 关联代码：`Assets/Scripts/Desktop/DesktopWindowController.cs`、`Assets/Editor/DesktopWindowPlayerSettings.cs`、`Assets/Scripts/UI/CoreLoopBootstrap.cs`  
> 关联文档：[游戏设置系统](游戏设置系统.md)、[背包与物品界面](背包与物品界面.md)

## 一、设计目标

《史莱姆盲盒》是一款常驻桌面的陪伴型游戏。游戏不占满屏幕，只有一座漂浮的小岛停在桌面上，玩家照常工作，随时看一眼岛上的史莱姆，或者顺手开个盲盒。

## 二、主界面形态

- 主界面是一片岛屿，培养皿、史莱姆和盲盒产出都在岛上表现。
- 岛屿以外的区域完全透明，玩家能直接看到后面的桌面和其他窗口。
- 背包、盲盒、图鉴等功能页面在岛屿窗口范围内以面板或弹窗展开，不另开新窗口。
- 当前实现：首页以 `Sprites/MainPage/Island/Island.png` 作为主视觉，布局见 [岛屿主界面](岛屿主界面.md)。岛屿贴图开启 Read/Write 以支持按 Alpha 命中。

## 三、窗口规格

| 项目 | 规则 |
| --- | --- |
| 窗口尺寸 | 固定 `800×800` 像素，玩家不可拉伸缩放 |
| 边框 | 无边框，无标题栏和系统按钮 |
| 背景 | 透明，只渲染岛屿和 UI 本身 |
| 显示模式 | 只有桌面窗口一种，不提供全屏或分辨率切换 |
| 任务栏 | 保留任务栏图标，方便找回和关闭 |
| 多开 | 只允许运行一个实例 |
| 帧率 | 限制为 30 FPS，失去焦点后继续运行，保证常驻时占用低且能检测鼠标 |

当前按物理像素 `800×800` 实现。高 DPI 显示器上是否按系统缩放比例放大，待确认。

## 四、拖动与位置

- 玩家按住岛屿、顶栏、底栏、卡片等可见区域可以把整个游戏窗口拖到桌面上任意位置；按钮、下拉框和滚动列表保留自身交互，不触发拖动。
- 拖动结束后保存窗口位置（`PlayerPrefs`：`desktop.window.x`、`desktop.window.y`），退出游戏时也会保存，下次启动时恢复。
- 窗口至少保留 120 像素在所在显示器的工作区内，防止拖出屏幕后找不回来。保存的位置不在任何显示器上时（如拔掉副屏），窗口回到主屏幕工作区中央。首次启动同样居中。
- 支持在多显示器之间拖动。

## 五、透明区域交互

- 透明区域的鼠标点击穿透到下面的桌面或其他窗口。
- 岛屿图片只在不透明像素上响应点击（贴图开启 Read/Write，Alpha 阈值 0.1）；按钮、卡片等其他可见 UI 按其矩形区域响应。
- 文字和 Alpha 为 0 的布局容器不视为可见区域。

## 六、待确认

- 窗口是否默认置顶，以及是否在设置里提供“始终置顶”开关（当前不置顶）。
- 原案中的“极简长条窗口”和“吸附屏幕边缘”是否作为后续的附加模式保留。
- 高 DPI 下的窗口缩放规则。
- 是否增加托盘图标或任务栏右键菜单作为额外退出入口（当前在设置弹窗中退出）。

## 七、技术实现（Windows）

- **启动**：`CoreLoopBootstrap` 在场景加载后挂载 `DesktopWindowController`；场景加载前设置 `800×800` 窗口化、后台运行和 30 FPS。
- **透明**：相机清屏为 `(0,0,0,0)`，关闭 HDR 和后处理以保留帧缓冲 Alpha；窗口样式改为 `WS_POPUP`，并调用 `DwmExtendFrameIntoClientArea`（边距 -1）让 DWM 按逐像素 Alpha 合成。
- **拖动**：鼠标按下时记录光标和窗口位置，按住期间每帧用 `SetWindowPos` 移动窗口，松开后限制在屏幕内并保存。
- **点击穿透**：每帧读取系统光标位置做 UI 射线检测；光标不在可见 UI 上时给窗口加上 `WS_EX_LAYERED | WS_EX_TRANSPARENT`，回到可见 UI 上时移除。
- **Player 设置**：`DesktopWindowPlayerSettings` 在项目加载和每次构建前自动校正，也可通过菜单 `Slime/Desktop/Apply Desktop Window Player Settings` 手动执行。设置内容为默认 `800×800`、窗口化、不可缩放、禁止全屏切换、后台运行、单实例，并关闭 DXGI 翻转模型交换链（开启时透明区域会显示为黑色）。
- 原生窗口能力只在 Windows Player 构建中生效；Unity Editor 中按普通 Game 视图运行，相机背景显示为深灰色便于查看布局。

## 八、验收标准

- 首次启动时窗口为 `800×800`，无边框，位于主屏幕中央，岛屿以外区域能看到桌面。
- 按住岛屿可拖动窗口，松开后位置保持；重启游戏后恢复到上次位置。
- 点击岛屿外的透明区域时，操作落到下面的桌面或窗口；移回岛屿后可以正常点击按钮。
- 窗口不能被拖到完全不可见；显示器配置变化后窗口仍能出现在屏幕内。
- 各功能页面都在 `800×800` 范围内完整显示，没有内容被裁切。
